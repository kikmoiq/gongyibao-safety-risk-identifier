# 双基发射药连续化生产线工艺包（演示示例 · 脱敏/虚构）

> 本文件为**演示用示例工艺包**，用于测试《工艺包安全风险辨识系统》对**双基（硝化棉+硝化甘油）发射药连续化生产线**的辨识能力。
> 内容为行业通用技术常识的**脱敏虚构**，非任何单位的真实工艺数据；涉及军品须按保密规定另行管理。

---

## 一、基础信息

### 1. 项目概述

本工艺包以精制棉、硝化甘油为主要能量组分，经**连续硝化、驱水、塑化捏合、压伸造粒、烘干、钝感包覆、混同包装**等工序生产**双基发射药**。产线采用**连续化+自动化**改造：以**防爆机器人、桁架机械手、AGV 输送系统、防爆巡检机器人**替代高敏感区的直接人工操作，实现**人机隔离、定员定量**管控。

### 2. 主要技术指标

- 生产能力：双基发射药 8000 t/a；年操作时间 6000 h。
- 硝化温度 25~35 ℃；捏合塑化 50~70 ℃；压伸成型 45~65 ℃、8~15 MPa；烘干 50~65 ℃。
- 硝化甘油含量 20%~40%（质量分数，按牌号调整）。
- 在线药量控制：高敏感工位单点在线药量 ≤ 5 kg；抗爆间室单人作业。
- 主要原料：精制棉、硝酸、硫酸、硝化甘油、二硝基甲苯（DNT）、丙酮（驱水剂）、二号中定剂。

### 3. 自动化系统构成

- **防爆机器人**：捏合塑化工位上下料与料桶搬运，本体防爆等级 Ex db IIB T4。
- **桁架机械手**：压伸成型工位模具搬运与制品接取，配安全光幕与限位保护。
- **AGV 输送系统**：工序间湿药、药粒、空桶转运，激光雷达防撞、限速、专用充电区。
- **防爆巡检机器人**：硝化甘油区、溶剂区气体与温湿度巡检。
- 控制系统：DCS + 安全 PLC（急停、安全光幕、通信中断安全停车），并设**定员定量在线管理**与作业许可系统。

## 二、物料安全风险辨识及防控措施

### 1. 硝化甘油（NG）

| 化学品中文名称 | 硝化甘油 |
| CAS No. | 55-63-0 |
| 危险性类别 | 爆炸品；第 6.1 类毒害品 |
| 健康危害 | 经皮肤吸收迅速，引起血管扩张性头痛、血压下降，长期接触致耐受与戒断反应。 |
| 燃爆危险 | 对撞击、摩擦、热极其敏感，微量即可引发爆轰；冻结后融化过程中危险性显著升高。 |
| 危险特性 | 与酸、碱、氧化剂接触分解放热；管道内滞留、结垢摩擦是典型事故诱因。 |
| 操作注意事项 | 全程水相或乳化状态输送；**严禁冻结**（库温 ≥ 5 ℃）；管道定期清洗防结垢；机器人夹持失效保护。 |
| 储存注意事项 | 单独抗爆库房、定员定量、防冻防暴晒，与雷管等起爆器材**严禁同库存放**。 |

### 2. 硝化棉（含氮量≥12.5%）

| 化学品中文名称 | 硝化棉 |
| 危险性类别 | 易燃固体（兼有爆炸性） |
| 健康危害 | 粉尘刺激呼吸道与皮肤。 |
| 燃爆危险 | 极易燃，遇明火、高热、摩擦、撞击或静电放电均可燃爆。 |
| 危险特性 | 干燥状态易自燃，安定性不足时自加速分解。 |
| 操作注意事项 | 保持含水；防静电与防摩擦撞击；控制在线药量。 |
| 储存注意事项 | 湿态储存于防爆防雷库房，与酸、氧化剂隔离，定期检测安定性。 |

### 3. 丙酮

| 化学品中文名称 | 丙酮 |
| CAS No. | 67-64-1 |
| 危险性类别 | 第 3.1 类低闪点易燃液体 |
| 健康危害 | 麻醉与刺激作用，高浓度致头晕、昏迷。 |
| 燃爆危险 | 极易燃，闪点约 -20 ℃，爆炸极限 2.5%~13%（V/V）。 |
| 危险特性 | 蒸气比空气重，可沿地面积聚至远处遇火源回燃。 |
| 操作注意事项 | 密闭输送、防爆电气、导静电接地，驱水工位设 LEL 在线检测。 |
| 储存注意事项 | 阴凉通风、远离火种热源与氧化剂，防静电积聚。 |

### 4. 二硝基甲苯（DNT）

| 化学品中文名称 | 二硝基甲苯 |
| CAS No. | 25321-14-6 |
| 危险性类别 | 第 6.1 类毒害品；可燃（有爆炸危险性） |
| 健康危害 | 剧毒，经皮肤与呼吸道吸收，致高铁血红蛋白血症、肝损伤。 |
| 燃爆危险 | 可燃，粉尘与空气形成爆炸性混合物；受强热可分解爆炸。 |
| 操作注意事项 | 密闭自动投料、负压排风、控制粉尘、个体防护与皮肤清洗。 |
| 储存注意事项 | 阴凉干燥、与强氧化剂及火源隔离，防粉尘扬散。 |

### 5. 硝酸

| 化学品中文名称 | 硝酸 |
| CAS No. | 7697-37-2 |
| 危险性类别 | 第 8.1 类酸性腐蚀品；氧化剂 |
| 健康危害 | 强腐蚀，酸雾吸入可致化学性肺炎。 |
| 燃爆危险 | 强氧化剂，与有机物、还原剂接触剧烈反应可致燃爆。 |
| 操作注意事项 | 密闭投料、局部排风、碱吸收；自动化投料减少人接触。 |
| 储存注意事项 | 与还原剂、碱类、易燃物分开，设防泄漏围堰与中和设施。 |

## 四、工艺流程简述（含自动化）

- 储罐区：储存硝酸、硫酸、丙酮，罐区设氮封、喷淋降温、静电接地与防火堤。
- 硝化工序：精制棉连续硝化，硝化温度 25~35 ℃，夹套冷却水带走反应热，出料为含酸硝化棉。
- 驱酸工序：离心驱除游离酸，稀酸回收后返回硝化。
- 煮洗工序：95~100 ℃、0.3~0.5 MPa 多级逆流煮洗去残酸，提高安定性，煮洗水 pH 在线检测。
- 驱水工序：以丙酮置换水分，温度 ≤35 ℃，丙酮回收精馏返回使用。
- 硝化甘油配制工序：连续喷射硝化制得硝化甘油水乳液，**全程水相输送、严禁冻结**，配碱洗、水洗。
- 捏合塑化工序：防爆机器人 R1 上下料，硝化棉/硝化甘油/中定剂在 50~70 ℃ 捏合塑化均匀，超温联锁停搅拌。
- 压伸成型工序：桁架机械手 R2 上下料，螺杆挤压成型造粒，45~65 ℃、8~15 MPa。
- 溶剂驱除工序：50~60 ℃ 热风驱除残留溶剂，在线监测蒸气浓度，挥发分 ≤1.2%。
- 钝感包覆工序：包覆剂在转鼓中均匀包覆药粒，降低表面感度，转速与温度联锁。
- 烘干工序：50~65 ℃ 分段烘干至水分 ≤0.7%，热风循环温度联锁。
- 混同包装工序：药粒混同检验后防静电包装，包装间定员 ≤2 人。
- 工序间转运：AGV 输送系统 R3 沿固定路径转运湿药、药粒与空桶。
- 全装置巡检：防爆巡检机器人 R4 对硝化甘油区、溶剂区与关键设备自主巡检。
- 溶剂回收工段：丙酮精馏回收，真空操作、塔顶温度 ≤75 ℃，定期检测过氧化物。
- 污水处理站：含酸、含硝基物废水经中和、沉降、活性炭吸附处理。
- 消防与雨淋系统：重点工房设雨淋/水幕、自动喷淋与防爆泄爆面。
