# 工业雷管装配生产线工艺包（演示示例 · 脱敏/虚构）

> 本文件为**演示用示例工艺包**，用于测试《工艺包安全风险辨识系统》在**含自动化装备但无参考文件章节**情况下的辨识与报告表现。
> 内容为行业通用技术常识的**脱敏虚构**，非任何单位的真实工艺数据；涉及军品须按保密规定另行管理。

---

## 一、基础信息

### 1. 项目概述

本工艺包以**基础雷管（含起爆药与猛炸药装药）**为对象，经**管壳准备、一次装药、压药、二次装药、加强帽装配、压合、点火元件装配、电性能检测、编码打标、包装**等工序完成**工业电雷管/导爆管雷管**装配。产线实施**自动化改造**：以**防爆装配机器人、桁架机械手、AGV 输送系统**替代高敏感工位的直接人工操作，并配套**定员定量与防静电**管控。

### 2. 主要技术指标

- 生产能力：工业雷管 3000 万发/a；年操作时间 4500 h。
- 装药量：一次装药 0.20~0.35 g；二次装药 ≤0.6 g（按品种）；压药压力 30~80 MPa。
- 压合压力 20~40 MPa；检测电压 ≤1000 V（防静电检测）。
- 在线药量：单个抗爆间室 ≤ 200 g；传递窗单次 ≤ 20 发。
- 主要物料：叠氮化铅（LA）、四氮烯（TNR）、黑索今（RDX）、太安（PETN）、管壳（铜/铝/塑料）、加强帽、脚线。

### 3. 自动化系统构成

- **防爆装配机器人**：一次/二次装药与压药工位上下料，本体防爆等级 Ex db IIB T4。
- **桁架机械手**：加强帽装配与压合工位物料搬运，配安全光幕与限位保护。
- **AGV 输送系统**：工序间药盒、管壳盒转运，激光雷达防撞、限速、专用充电区。
- 控制系统：DCS + 安全 PLC（急停、安全光幕、通信中断安全停车），并与定员定量管理系统联动。

| CAS No. | 121-82-4 |
| 危险性类别 | 爆炸品；第 6.1 类毒害品 |
| 健康危害 | 经皮肤与呼吸道吸收，引起头痛、恶心、癫痫样症状。 |
| 燃爆危险 | 撞击与摩擦感度较高，大量堆积燃烧可转为爆轰。 |

| 化学品中文名称 | 叠氮化铅 |

| 化学品中文名称 | 金属管壳与脚线 |

| 健康危害 | 机械伤害为主，铜屑可能形成敏感铜盐。 |

## 四、工艺流程简述（含自动化）

- 管壳准备工序：管壳清洗、烘干与检查，剔除变形与带毛刺壳体，金属屑专人清理。
- 一次装药工序：防爆装配机器人 R1 定量装起爆药（0.20~0.35 g），在线称量复核超差剔除。
- 压药工序：30~80 MPa 压药成型，压力与保压时间联锁，压力异常自动卸载。
- 二次装药工序：装填 RDX/PETN 猛炸药 ≤0.6 g，限量投放并有防粉尘积聚措施。
- 加强帽装配工序：桁架机械手 R2 完成加强帽上料与装配，避免金属件直接摩擦起爆药。
- 压合工序：20~40 MPa 压合，装压到位检测，压合超压自动停机。
- 点火元件装配工序：脚线焊接与桥丝装配，焊接工位与药料区物理隔离，防静电接地。
- 电性能检测工序：≤1000 V 防静电检测，检测电压与限流电阻双重保护，不良品自动剔除。
- 编码打标工序：激光/喷码打标，读码复核，编码数据上传 MES。
- 包装工序：定量装盒（≤100 发/盒），防静电包装材料，包装间定员 ≤2 人。
- 工序间转运：AGV 输送系统 R3 沿固定路径转运药盒与管壳盒。
- 成品暂存与出厂：成品库单独设置，与起爆药原料库分库、与起爆器材成品区按安全距离布置。
- 除尘与废药处理工序：药粉尘除尘收集，废药与不合格品限量分批销毁。
