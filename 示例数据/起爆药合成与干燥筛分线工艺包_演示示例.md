# 起爆药（叠氮化铅·四氮烯）合成与干燥筛分线工艺包（演示示例 · 脱敏/虚构）

> 本文件为**演示用示例工艺包**，用于测试《工艺包安全风险辨识系统》在**无自动化装备台账**、**风险表列名非常规**情况下的辨识能力。
> 内容为行业通用技术常识的**脱敏虚构**，非任何单位的真实工艺数据；涉及军品须按保密规定另行管理。

---

## 一、基础信息

### 1. 项目概述

本工艺包以叠氮化钠、硝酸铅、氨基四唑等为原料，经**中和、络合沉淀、结晶、过滤洗涤、真空干燥、筛分、装盒**等工序生产**叠氮化铅（LA）**与**四氮烯（TNR）**起爆药。起爆药对热、撞击、摩擦、静电**极度敏感**，全线以**人机隔离、抗爆间室、定员定量、远距离操作**为核心安全策略，**未设置机器人/机械手等自动化装备**（本示例用于验证系统的空态表现）。

### 2. 主要技术指标

- 生产能力：叠氮化铅 120 t/a；四氮烯 8 t/a；年操作时间 4000 h（按定员定量间断作业）。
- 合成温度 45~60 ℃；真空干燥 50~60 ℃、真空度 ≥ -0.08 MPa。
- 起爆药在线药量：单个抗爆间室 ≤ 1 kg；干燥间单批 ≤ 0.5 kg。
- 主要原料：叠氮化钠、硝酸铅、氢氧化钠、硝酸、氨基四唑、糊精（造粒剂）。
- 定员：合成岗位 ≤ 2 人；干燥筛分岗位 ≤ 1 人；装盒岗位 单间 ≤ 1 人。

### 3. 自动化与仪表配置

- 本线**未配置机器人**，以固定式 DCS 远距离操作 + 视频监控 + 抗爆隔离墙实现人机分离。
- 仪表：温度/压力/液位/真空度远传，关键点设 SIS 联锁（超温自动切断加热与加料并注入冷却水）。
- 安全设施：抗爆间室、泄爆面、导静电地面（表面电阻 1×10⁴~1×10⁶ Ω）、静电消除器、雨淋与消防水幕、轻质泄爆屋面。

## 二、物料安全风险辨识及防控措施

### 1. 叠氮化铅（LA）

| 化学品中文名称 | 叠氮化铅 |
| CAS No. | 13424-46-9 |
| 危险性类别 | 爆炸品（第 1.1 项）；第 6.1 类毒害品 |
| 健康危害 | 有毒，抑制细胞色素氧化酶，接触后出现头痛、乏力；经皮肤与呼吸道吸收。 |
| 燃爆危险 | 对撞击、摩擦、静电放电、热**极其敏感**，起爆能力极强。 |
| 危险特性 | 与铜、锌等重金属接触生成更敏感的叠氮化物；与酸反应生成剧毒易爆的叠氮酸（HN₃）。 |
| 操作注意事项 | 湿态操作、限量投放；禁用铜锌工具与容器；远距离抗爆操作、导静电接地。 |
| 储存注意事项 | 单独抗爆库房、定员定量（≤1 kg/间），与起爆器材同库存放须按标准限定；防潮防暴晒。 |

### 2. 四氮烯（TNR）

| 化学品中文名称 | 四氮烯（4-胍基-1-四唑烯） |
| 危险性类别 | 爆炸品 |
| 健康危害 | 粉尘刺激呼吸道，长期接触不适。 |
| 燃爆危险 | 对热与摩擦敏感，起爆威力较低，但混入硬质杂质后感度显著升高。 |
| 操作注意事项 | 限量操作、避免混入砂粒与金属杂质、湿态过筛。 |
| 储存注意事项 | 单独存放，避免与强酸、强氧化剂及重金属盐接触。 |

### 3. 叠氮化钠

| 化学品中文名称 | 叠氮化钠 |
| CAS No. | 26628-22-8 |
| 危险性类别 | 第 6.1 类剧毒品 |
| 健康危害 | 剧毒，抑制呼吸链引起血压骤降、意识丧失。 |
| 燃爆危险 | 本身不燃，但受热或与酸接触生成剧毒易爆叠氮酸气体；与重金属接触生成敏感叠氮化物。 |
| 操作注意事项 | 密闭投料、负压排风、酸分离操作；严禁与酸混合；废液单独处理。 |
| 储存注意事项 | 单独库房、上锁管理、双人双锁，远离酸类。 |

### 4. 硝酸铅

| 化学品中文名称 | 硝酸铅 |
| CAS No. | 10099-74-8 |
| 危险性类别 | 第 6.1 类毒害品；氧化剂 |
| 健康危害 | 铅中毒，损害造血与神经系统。 |
| 燃爆危险 | 氧化剂，与可燃物混合受热或摩擦可燃爆。 |
| 操作注意事项 | 密闭溶解、通风排毒、个体防护与定期体检。 |
| 储存注意事项 | 与可燃物、还原剂分开，防潮防污染。 |

## 三、工艺流程简述

- 原料配制与计量：叠氮化钠、硝酸铅按批计量溶解，配碱液中和，pH 在线监测。
- 合成（络合沉淀）工序：控制温度 45~60 ℃，缓慢加料，搅拌速率与加料速率联锁。
- 结晶工序：降温结晶，晶粒均匀性由降温速率控制，避免晶粒间摩擦。
- 过滤洗涤工序：抽滤并多级水洗去除游离盐，洗涤水收集至含氮废水系统单独处理。
- 真空干燥工序：50~60 ℃、真空度 ≥ -0.08 MPa，干燥间单批 ≤0.5 kg，全程远距离视频监控。
- 筛分工序：湿态或惰性介质下过筛，禁用力学振动过筛，避免摩擦与撞击。
- 装盒工序：定量装盒（单盒 ≤50 g），抗爆间内单人操作，人工传递由传递窗完成。
- 废水处理工序：含叠氮废水经次氯酸钠氧化破氰/破氮处理后送污水处理站，严禁与酸混合。
- 废品销毁工序：限量分批在专用销毁场按规程烧毁，与作业区保持安全距离。
