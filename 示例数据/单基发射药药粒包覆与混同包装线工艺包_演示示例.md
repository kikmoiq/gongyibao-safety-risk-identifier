## 一、基础信息

### 1. 项目概述

本工艺包承接前段**单基发射药压伸造粒**半成品，完成**预烘、钝感包覆、表面石墨光泽、混同、成品烘干、筛分、包装与入库**等后处理工序。本段为**低敏感度相对较低**的工序段，但仍存在药粉尘燃爆、溶剂蒸气爆炸、静电与摩擦起爆等风险。**本段未配置机器人/机械手**，以固定设备与人工操作为主。

### 2. 主要技术指标

- 生产能力：药粒包覆/包装 3000 t/a；年操作时间 6000 h。
- 预烘温度 45~55 ℃；包覆温度 50~60 ℃；成品烘干 50~60 ℃。
- 石墨光泽工序转鼓转速 3~8 r/min（变频）。
- 包装间定员 ≤2 人；成品库单库区储存量按量-距离核算。
- 主要物料：单基发射药药粒、包覆剂（邻苯二甲酸二丁酯类）、乙醇（溶剂）、石墨（光泽剂）、二苯胺（安定剂）。

### 3. 主要设备与仪表配置

- 预烘/成品烘干设备：热风循环烘房，温度双点检测与联锁。
- 包覆设备：卧式转鼓，导静电接地，转速与温度联锁。
- 筛分设备：平面回转筛，禁用力学强振动，配除尘接口。
- 仪表：温度、湿度、粉尘浓度、溶剂蒸气浓度（%LEL）在线检测，超限报警并联锁停机。
- 安全设施：防静电地面、静电消除器、防爆电气、泄爆面、消防雨淋与水幕。

## 二、物料安全风险辨识及防控措施

### 1. 单基发射药药粒

| 化学品中文名称 | 单基发射药（硝化棉基） |
| 危险性类别 | 易燃固体（兼有爆炸性） |
| 健康危害 | 粉尘刺激呼吸道与皮肤。 |
| 燃爆危险 | 遇明火、高热、摩擦、撞击或静电放电均可燃爆；粉尘云有爆炸危险。 |
| 危险特性 | 安定性不足时热分解自加速，长期堆积发热可能自燃。 |
| 操作注意事项 | 控制在线药量、防粉尘积聚与飞扬、导静电接地、避免摩擦撞击。 |
| 储存注意事项 | 防爆防雷库房、通风干燥、与酸和氧化剂隔离、定期检测安定性。 |

| 化学品中文名称 | 乙醇 |

| 化学品中文名称 | 石墨粉 |

| 储存注意事项 | 阴凉干燥、防粉尘扬散、远离火源。 |

## 三、工艺流程简述

- 预烘工序：药粒在 45~55 ℃ 热风循环烘房预烘至水分 ≤2.0%，热风温度设双点联锁与超温切断。
- 钝感包覆工序：卧式转鼓内以包覆剂（邻苯二甲酸二丁酯类）在 50~60 ℃ 下均匀包覆药粒表面，降低表面感度；转鼓导静电接地，转速与温度联锁。
- 石墨光泽工序：转鼓内加入石墨粉 3~8 r/min 滚光，加料密闭、局部除尘，防石墨粉尘云形成。
- 混同工序：多批药粒在混同机内混同，保证性能均一；混同机设接地与限位，混同量按批控制。
- 成品烘干工序：50~60 ℃ 分段烘干至挥发分 ≤1.0%，热风温度与风量联锁，在线监测溶剂蒸气浓度（%LEL）超限报警并停机。
- 筛分工序：平面回转筛剔除结块与粉尘，筛下粉尘由除尘系统收集，禁用力学强振动设备。
- 包装工序：药粒定量包装（20~50 kg/包），采用防静电包装材料，包装间定员 ≤2 人，作业时除尘与接地。
- 入库工序：成品经检验合格后入成品库，库区通风干燥、与酸及氧化剂隔离，储存量按量-距离核算，设温湿度监测与火灾报警。

关键作业提示：
- 包覆与石墨工序转鼓进出料属**开盖作业**，须先确认转鼓停稳并可靠接地，作业区禁止明火与电火花。
- 筛分与包装区属于**粉尘作业区**，须定期清理积尘，禁止使用压缩空气吹扫药粉（应用湿法或负压吸尘）。
- 溶剂回收与输送系统的**导电跨接**每月检测一次，接地电阻每季度检测。
- 所有检修作业须办理作业许可，落实**动火、受限空间、临时用电**三类特殊作业审批；检修前必须**吹扫置换**并检测合格。
- 药粒在线上停留时间受控，**在线药量**超量时浇湿隔离；库房储存不得超期，定期抽检安定性。

## 四、工艺安全风险提示（要点式）

- 包覆转鼓超温可能引起药料热分解并燃爆 → 温度双点联锁停机、加冷却空气降温。
- 溶剂蒸气泄漏可能形成爆炸性混合物 → 防爆电气、LEL 报警联锁、密闭回收与通风。
- 石墨粉尘与药粉尘混合积聚，遇静电或电火花可能燃爆 → 防静电接地、定期清尘、禁用压缩空气吹扫。
- 筛分设备摩擦与堵塞发热 → 禁强振动设备、堵塞报警与停机检查。
- 包装区人员超编或交叉作业 → 定员定量挂牌管理、门禁与视频监督。
- 成品库超量储存与混存 → 量-距离核算、分区分库、温湿度监测与火灾报警。
- 检修动火与受限空间作业 → 作业许可、吹扫置换、气体检测与专人监护。
- 静电积累（包覆剂与药粉尘） → 导静电地面与鞋服、静电消除器、接地跨接。
- 长期堆积药料自燃 → 控制在线药量与停留时间、定期检测安定性、设置温度监测报警。
- 撞击与摩擦（异物混入） → 进料设磁选与筛除、禁止金属工具进入药料区。
